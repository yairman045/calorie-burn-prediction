# Dataset

This folder contains the dataset used in the Calorie Burn Prediction project.

Dataset: Gym Members Exercise Dataset
Source: https://www.kaggle.com/datasets/valakhorasani/gym-members-exercise-dataset

Expected file: gym_members_exercise_tracking.csv

The dataset contains workout and personal fitness measurements used to classify calories burned during exercise.
